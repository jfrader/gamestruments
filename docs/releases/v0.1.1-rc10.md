## What Changed Since rc8

- The internal project name was removed from buyer-visible artifacts. The racing
  recipe is publicly **Racing**:
  - Engine module and symbols renamed (`pocket_circuit` → `racing`), score ids
    are `racing-generated-…`, and the catalog path is `catalog/racing/…`.
  - The Godot addon's `recipe` defaults to `"racing"`; Suspense still uses
    `"suspense"`.
  - Audio Lab recipe ids, HTML, and CSS use `racing`/`suspense`; the committed
    WASM was rebuilt and source-verified.
  - Buyer docs, listing, contract, QA runbook, repo README, and the shipped
    changelog no longer reference the internal game. Internal planning docs keep
    it deliberately.
- Follow-up commits: PR #45 (rename), PR #46 (stale CI test references), PR #47
  (shipped changelog scrub).
