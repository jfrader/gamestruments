## What Shipped

- **Mastered output** (PR #73): every render now passes through one shared master
  stage — highpass, compressor, limiter — mirroring the Audio Lab chain, instead
  of hard-clipping the raw voice sum. Offline renders measure and normalise to
  −14 LUFS, then bound true peak, then clamp; the realtime path uses a fixed
  documented makeup plus the same limiter.
- Renders now sit at a normal listening level: **−14.94 … −14.04 LUFS** across
  the 12-render pack, spread **0.90 LU**, where they previously sat at
  **−31.07 … −35.75 LUFS** with a 4.7 LU spread.
- **Nothing reaches 0 dBFS.** True peak measures **−1.98 … −1.74 dBTP** against
  a −1.0 dBTP ceiling, enforced by a hard clamp backstop on both paths.
- Default render rate moves from **22 050 Hz to 48 000 Hz** across the engine,
  the WASM facade, the parity reference, the examples, and the Godot extension.
- Deterministic `exp`/`ln`/`log10`/`pow10`/`powf`/`sin`/`cos` in a new internal
  module, so native and WASM renders stay byte-identical.
- `Synth` and `FormAudio` no longer own the ceiling; the master stage does.

### Consumer impact

This raises library output roughly 20 dB and changes the sample rate. Existing
integrations keep the same API but will hear a level jump and should rebalance
against it. Pocket Circuit is the first consumer and needs its baked loops
re-generated and its engine/SFX balance revisited.

the current release.
